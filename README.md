# Morrow Recovery

A daily recovery app for serious athletes: morning check-in readiness, morning and night stretch routines with animated demos, sport- and position-specific recovery protocols, sleep planning and hydration tracking.

Hosted with GitHub Pages. Open the site on your phone and add it to your home screen to use it like an app. Data is stored on each person's own device.

## Files
- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`: the live site.
- `src/index.html`: the source page. Run `python3 src/build_site.py` to rebuild the site's `index.html` from it.
